# Sample Data

`sample_data/` contains checked-in example content.

- `1_source/people_nobel/` holds raw Nobel source inputs and normalized match caches used to build the Nobel sample.
- `1_source/people_isu_biotech/biotech_staff.json` holds the official Office of Biotechnology staff snapshot used to build the ISU biotech sample.
- `1_source/people_isu_biotech/tags/` holds the sample-local tag registry, aliases, and hierarchy used by the current ISU biotech build.
- `1_source/genomics_scn/` holds a local genomics source table plus standardized metadata files such as `dataset.yaml` and `schema.yaml` used to build the genomics sample.
- `2_vault/nobel/people/` holds the Obsidian-style markdown people vault generated by the Nobel sample build.
- `2_vault/nobel/abstracts/` holds publication abstract notes linked from the Nobel people vault.
- `2_vault/isu_biotech/` holds the generated markdown vault for the ISU biotech sample, and may also include rendered `acknowledgements/` notes.
- `3_db/nobel50.db` is the built 50-laureate sample graph database.
- `3_db/isu_biotech.db` is the built ISU biotech sample graph database.
- `3_db/genomics_scn.db` is the built genomics sample graph database.
- `3_db/vault.seed.db` is the tracked starter database used to bootstrap first launch.

This directory is intended to be versioned.
