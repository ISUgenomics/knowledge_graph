# KGX Session Notes — 2026-05-31

## What Was Built

Built the Knowledge Graph Explorer from Phase 3 through Phase 6:

- **Chat-to-SQL panel** — Natural language queries via Ollama (qwen3-coder:30b), with result tables, mutation preview + confirm dialog, and multi-turn history
- **Skill dispatch** — Right-click a person node → "Research person..." runs the LangGraph skill as a subprocess with live SSE output streaming to the chat panel
- **DB file watcher** — SSE endpoint polls vault.db mtime; graph + sidebar auto-refresh when skills write new data
- **Node text labels** — Three.js sprite labels on high-degree nodes (degree >= 3 threshold on large graphs)
- **Global search** — Header search bar with debounced LIKE query and dropdown results
- **Context menu** — Right-click actions: Show Detail, Focus, Expand Neighbors, Hide Node, Research Person, Copy ID
- **Edge type filters** — Sidebar checkboxes to toggle relationship types on/off
- **Export buttons** — JSON and Neo4j CSV export (zip) from header

## What Was Fixed

### Critical

- **Route ordering bug** — `{entity_id:path}` catch-all swallowed `/neighbors` and `/markdown` routes, returning 404. Fixed by registering specific routes before catch-all.
- **SQL injection in `_preview_query`** — Table name extracted via `sql.split()[2]` without validation. Fixed with `_ALLOWED_TABLES` allowlist.
- **TOCTOU race in `upsert_entity`** — SELECT-then-INSERT replaced with `INSERT...ON CONFLICT DO UPDATE`.

### High

- **Thread safety** — Single SQLite connection shared across threads without locking. Added `threading.Lock` on all write operations + WAL mode.
- **Edge filter "explosion"** — Toggling edge filters called `graphData()` which restarts the force simulation. Rewrote to use `__hidden` flags + `nodeVisibility`/`linkVisibility` callbacks (no simulation restart).
- **XSS vulnerabilities** — Unescaped user input in sidebar search and global search innerHTML. Added `escHtml()`/`escH()` functions.
- **SSE stream leak** — Watch endpoint's `while True` loop never terminated. Added `request.is_disconnected()` check.
- **Resource leak** — OllamaClient httpx connection never closed. Added shutdown handler.

### Medium

- **Camera divide-by-zero** — `Math.hypot(0,0,0)` → `Infinity` in distRatio. Added guard.
- **Broken color sync** — Sidebar tried reading nonexistent `canvas._kgxTypeColors`. Fixed by emitting `typeColors` in `graph:loaded` event.
- **`execute_read` rejecting CTEs** — Only accepted `SELECT`. Fixed to also accept `WITH`.
- **Checkbox reset on reload** — `loadGraph()` cleared `hiddenRelTypes`. Now preserves filter state across reloads.

## Performance

- 5,356 nodes + 11,498 edges loads in ~21ms, 1.4MB JSON payload
- Labels limited to degree >= 3 on graphs with > 500 nodes
- Visibility toggling uses flag mutation + function reference swap (no simulation restart)
